## Language policy

The public documentation surface is maintained as English + Indonesian semantic companions.

- The compatibility/default English filename remains unsuffixed for most documents.
- Indonesian companions use `-ID.md`.
- Progress Liveness already uses explicit `-EN.md` / `-ID.md`; that existing convention is preserved.
- Paths, identifiers, code tokens, gate names, schema field names, and commands remain unchanged across languages.
- A language companion must not widen authority or create a behavior that is absent from the executable source contract.
